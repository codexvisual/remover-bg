Background removal API

A simple REST endpoint that turns an image into a transparent PNG. Integrate it in minutes with any language.

On this page

OverviewAuthenticationEndpoint Code examplesResponseErrorsBulk & webhooks

Overview

Send an image file with a POST request and receive a cut-out PNG. The API accepts JPG, PNG, WebP and BMP input up to 15 MB.

Fast

Typical response in 2–5 seconds.

Secure

HTTPS only, API key authentication.

Global

Available from anywhere.

Authentication

Pass your API key in the X-API-Key header. Keep the key on your server — never expose it in client-side code.

HTTP header
X-API-Key: your_api_key_here

Endpoint

POST
POST https://api.remove.bg/v1.0/removebg
Content-Type: multipart/form-data

image_file: @photo.jpg
size: auto

This demo site also ships with a ready-to-use server proxy at api/remove.php. Set your key there and point assets/js/config.js to it.

Code examples

cURL

curl
curl -H "X-API-Key: YOUR_KEY" \
  -F "image_file=@photo.jpg" \
  -F "size=auto" \
  https://api.remove.bg/v1.0/removebg \
  -o result.png

JavaScript (fetch)

JavaScript
const form = new FormData();
form.append('image_file', file);

const res = await fetch('https://api.remove.bg/v1.0/removebg', {
  method: 'POST',
  headers: { 'X-API-Key': API_KEY },
  body: form
});
const blob = await res.blob();

Python

Python
import requests

response = requests.post(
    'https://api.remove.bg/v1.0/removebg',
    headers={'X-API-Key': 'YOUR_KEY'},
    files={'image_file': open('photo.jpg', 'rb')},
    data={'size': 'auto'}
)
with open('result.png', 'wb') as f:
    f.write(response.content)

PHP

PHP
$ch = curl_init('https://api.remove.bg/v1.0/removebg');
curl_setopt_array($ch, [
  CURLOPT_HTTPHEADER => ['X-API-Key: YOUR_KEY'],
  CURLOPT_POSTFIELDS => ['image_file' => new CURLFile('photo.jpg')],
  CURLOPT_RETURNTRANSFER => true
]);
file_put_contents('result.png', curl_exec($ch));

Response

A successful request returns the PNG file itself. If you request JSON callbacks, you receive metadata like this:

200 OK
{
  "data": {
    "result_url": "https://...",
    "width": 1024,
    "height": 1024
  }
}

Errors

StatusMeaning
400Invalid or missing image
401Invalid API key
402Out of credits
429Rate limit reached
500Processing failed — retry

Bulk jobs & webhooks

For large batches, upload a ZIP file or use the async endpoint with a webhook_url. Your server receives a POST when the job finishes.

Async request
{
  "image_file": "@...",
  "webhook_url": "https://yoursite.com/hooks/removebg"
}
